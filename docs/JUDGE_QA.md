### Q3: How is AgentProof different from ERC-8004 reputation?

"ERC-8004 reputation records registered metadata URI claims and onchain feedback entries. AgentProof is an independent operational monitoring layer that continuously probes agent endpoints for real-time reachability, observation count, and median latency. AgentFlow keeps self-reported registry metadata strictly separate from measured AgentProof operational passports."
